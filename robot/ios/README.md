# FriendBot iOS app

Xcode + CocoaPods project for the FriendBot robot app (based on the [OpenBot](https://www.openbot.org) iOS app).

* Build / install / use: **[docs/IOS_APP.md](../../docs/IOS_APP.md)**
* Quick build: `cd OpenBot && pod install && open OpenBot.xcworkspace`
* Voice Control code: `OpenBot/OpenBot/Controllers/VoiceControl/`
